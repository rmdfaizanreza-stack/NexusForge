## How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rmdfaizanreza-stack/NexusForge.git
   ```

2. **Open in browser:**
   - Navigate to the project folder
   - Open `index.html` in your web browser

3. **Explore Games:**
   - Browse featured games
   - Click on categories to filter

   - Click download to get a game

## Customization

### Add More Games
Edit `script.js` and add to the `games` array:

```javascript
{
    id: 13,
    name: "Your Game",
    category: "action",
    rating: 4.5,
    reviews: 1000,
    image: "fa-icon-name",
    description: "Game description",
    developer: "Developer Name",
    platform: "Web, Mobile",
    size: "20 MB",
    version: "1.0.0",
    downloads: "500K+"
}
```

### Change Colors
Modify CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    --dark-bg: #0f172a;
    /* ... more variables */
}
```

### Modify Styling
- All styles are in `styles.css`
- Uses CSS Grid and Flexbox for layout
- Mobile responsive breakpoints included
